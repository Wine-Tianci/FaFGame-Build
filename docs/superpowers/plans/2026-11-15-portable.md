# Portable Windows Build Tool Implementation Plan

> For agentic workers: execute inline with executing-plans; use an independent reviewer for the plan and completed work.

**Goal:** Deliver an offline Windows x64 ZIP with bundled dependencies and double-click Jenkins launch.

**Architecture:** Keep existing build scripts and local deployment intact. New release assembler copies an explicit whitelist into a fresh output, validates dependency hashes, and writes a relative manifest. New portable launcher handles local configuration, provisioning, readiness and process-local PATH; trusted Groovy configures a clean authenticated Jenkins instance. No source files or existing credentials enter the release.

**Tech Stack:** Windows PowerShell 5.1, cmd, Jenkins/Groovy, Zulu JRE 21, Git for Windows, Godot 4.7.2.

- [x] Task 1: Add tests/Portable.Tests.ps1 with failing behavioral tests for dependency resolution after relocation, missing dependencies, conflicting source/output, lock mismatch, clean package whitelist and fresh-only assembly. Run with powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Portable.Tests.ps1.
- [x] Task 2: Create scripts/Portable-Helpers.ps1, scripts/New-PortablePackage.ps1, portable/Start.cmd, portable/Stop.cmd and portable/README.md. Reuse path safety and process helpers; package full supplied Git directory, checked JRE and standalone Godot, six pinned templates, and plugins verified against both lock files. Generate portable-manifest.json with relative paths and hashes. Test assembler using lightweight fixtures and real dependencies.
- [x] Task 3: Create scripts/Start-Portable.ps1, scripts/Stop-Portable.ps1 and portable/bootstrap.groovy. Preserve existing Start-Jenkins behavior; add optional child Git path and Java options only as needed with regression coverage. Implement persisted source/port config, first-run plugins/bootstrap, generated per-instance admin credentials/API token, restricted local authentication, idempotent task setup, readiness polling and graceful stop. Token never in command line or log. Test against real Jenkins.
- [x] Task 4: Assemble real standalone dependency ZIP in dist; extract to a fresh Unicode/spaces path and verify with system Java/Git absent from child PATH. Run authentication and parameters-page probes without printing secrets. Build a tiny standalone Git/Godot fixture in Debug and Release. Stop test instance, relocate and restart. Run existing Jenkins and dependency tests; update documentation and verification evidence; have independent reviewer inspect final files.

Workspace is not a Git repository; no branch, worktree or commit actions apply here. Do not start or stop the existing local Jenkins during acceptance. All test instances get independent homes and unused ports.

Final evidence: 22 portable checks, 24 real Jenkins acceptance checks, 48 existing Jenkins launcher checks, and 16 dependency checks passed. ZIP extracted and all 791 manifest hashes matched. Existing Build-Windows.Tests.ps1 independently failed its first mock case because its child PowerShell returned -1 with no output; this remains recorded as an unresolved test-harness/environment issue, not counted as passing. Detailed limitations and evidence are in PORTABLE_RELEASE.md.
